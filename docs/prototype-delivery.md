# CueLearn 学习主路径原型交付说明

## 打开与提交

提交仓库根目录的 `CueLearn-学习原型.zip`。先解压，再双击包内 `index.html`，无需安装Node、启动后端或联网。不要提交整个仓库；ZIP只含3个HTML、1个独立CSS和4张关键页面PNG。

根目录临时预览入口为 `prototype-learning.html`，另有 `prototype-notebook.html`、`prototype-report.html` 和 `prototype.css`。仓库原有 `index.html` 是Electron/Vite启动入口，保持原状；交付包中的 `index.html` 才是课程原型入口，链接已调整为包内相对路径。

## 演示顺序与核心用户故事

作为视频学习者，我想在原句中理解并收藏单词，通过主动回忆和资料核对检验理解，以便把视频内容转化为能够再次提取的知识。

1. **目标与内容**：从首页阅读本轮目标，浏览视频场景及字幕，点击「查看词义」「收藏当前语境」。播放及时间定位为明确标注的模拟，不加载真实视频。
2. **学习活动**：选择「基础引导」或「独立挑战」，先尝试回忆，再显示释义。选择错误答案会得到具体解释；改选正确答案后才解锁自评。
3. **即时反馈**：先故意选「一场比赛」，查看context与contest的区别，再选择正确含义；提交「忘记／模糊／记得」，观察完成数量和下一步入口。
4. **探究与核对**：前往笔记本，点击回答旁引用编号，核对字幕及时间；可操作摘要、笔记、演示提问与小测验。回答均是预写样例，未调用模型。
5. **纠错与评价**：测验先答错，阅读原句提示后重试；答对后进入评价页，看到回忆、核对来源、测验三项目标完成情况及下一步建议，再回到复习。

## 对应课程要求

| 要求 | 原型呈现与验收方式 |
| --- | --- |
| 覆盖主路径 | 首页收藏与复习 → 笔记本来源核对 → 测验 → 学习评价，可按下一步连续浏览 |
| 学习闭环 | 明确目标、字幕内容、回忆活动、正误解析、自评及三项目标评价 |
| 即时反馈 | 词义题和测验均有针对性解释、来源提示、纠错重试；学习与采集失败状态分开 |
| 降低认知负荷 | 三项导航、分区信息、先回忆后揭示、按步骤开放后续操作 |
| 教育语境 | 基础引导提供语义线索，独立挑战隐藏支架；文案鼓励回忆和改正，无速度排名 |
| 教学策略 | 情境学习：原句与时间点；检索练习：先回忆后揭示；纠错学习：解释后重试；探究学习：围绕资料提问并核对依据 |
| 伦理与保护 | 各页呈现合成数据、不联网、个人信息保护、无公开排名、适时休息和随时退出；明确AI样例及资料边界 |
