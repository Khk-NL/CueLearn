# CueLearn 课程学习开发说明

产品定位、开源项目分工与后续复用原则见[产品定位与开源复用路线](product-positioning.md)。本文记录当前功能与运行配置；规划中的语义检索和社区能力不计入当前验收。

## 功能流程

1. 启动 PocketBase，打开 CueLearn 的「语境学习」页，保存本机或 HTTPS 服务地址，注册并登录。
2. 每个 PocketBase 服务和账号首次在本机登录时，由用户选择是否导入本机旧生词；以后仍可使用页面上的「导入本机生词」按钮。导入只增加账号记录，不删除本地词表；重复词条跳过。
3. 在播放器的字幕中查词并收藏。已登录时，应用将单词、原句、视频指纹、字幕序号和秒数保存到当前账号；本地收藏仍保持原有行为。
4. 在「生词复习」逐张查看到期卡片，先根据原句和视频原声回忆，再显示释义并选择「忘记／模糊／记得」。大量旧生词导入时只渲染当前一张，待复习总数仍完整统计。三档分别映射到 FSRS 的 Again／Hard／Good；排程只从 `review_events` 作答历史重建，统计展示到期数、今日完成数和近七日记得比例。短期复习到期后页面会自动更新队列。
5. 创建笔记本，选择最多五个已有视频，可移除资料后换入其他视频。所选视频需有字幕。可以提问、生成摘要、小测验、保存手写笔记；AI 回答按论述标注字幕编号，点击编号或出处可跳转到原视频时间点。移除资料只改变后续问答的范围，已保存笔记和测验仍保留原出处。

## 数据和边界

PocketBase 0.40 系列使用 `pb_migrations/202610010000_course_learning.js` 建立 `vocabulary_items`、`word_contexts`、`review_events`、`notebooks`、`notebook_sources`、`notes` 和 `quiz_attempts` 等集合。迁移还建立了 `events`，但当前应用没有写入或读取它，统计以复习事件和词条为依据，不应把通用学习行为采集列为已实现功能。每个业务集合都有 `owner`，服务端集合规则限制本人读写。视频文件不上传；`media_key` 是文件大小及首尾采样的 SHA-256 指纹，本机路径仅保存在应用本机设置中。

笔记本问答只读取当前笔记本选中资料的字幕。主进程为字幕行编号，要求模型将每条论述关联到字幕编号，再映射为正文中的可点击引用；未知编号会报错。旧版没有正文编号的已保存笔记仍展示出处列表。资料为空、字幕太短、超出首版处理范围、字幕已变化或本机文件缺失时会显示明确提示。AI 服务没有配置时不会伪造回答。

登录令牌只保存在主进程内存中；退出登录、切换 PocketBase 地址或重启应用后需要重新登录。PocketBase 网络中断时，学习操作显示请求错误；本地播放和原有本地词表不依赖学习服务。

首次以 CueLearn 名称启动时，应用会在新的用户资料目录尚无对应文件时复制旧版配置、本地数据库和播放器偏好；原目录不删除。复制先进入临时文件，再原子改名，避免把半途失败的复制当作成功。默认文档存储会按当前运行环境检查 `CueLearn` 或 `CueLearn-dev`，只在对应旧目录存在时选择旧目录并记录日志；用户也可在设置中明确选择新的存储位置。

## 本机启动

项目要求 Node.js 22 和 Yarn 1。将官方 PocketBase 0.40 系列可执行文件放在仓库根目录、`.local/pocketbase/` 或系统 PATH 中。Windows 可在仓库根目录运行 `start-pocketbase.cmd`，脚本会从 8090 起选择空闲端口；在应用「语境学习」页填写脚本显示的地址。也可以手动执行：

```powershell
pocketbase serve --dir pb_data --migrationsDir pb_migrations
yarn install --frozen-lockfile
yarn start
```

开发机可以分别在两个终端运行前后端。首次运行 `yarn start` 会执行上游资源下载脚本。请勿把 `pb_data/`、本机用户资料、视频、字幕或密钥提交到 Git。

远程服务由使用者最后填写：在「语境学习」设置 HTTPS PocketBase URL，在「设置 → 服务与资源」设置 AI 接口地址、密钥和模型。仓库不包含远程服务地址或凭据。Gitee 镜像仓库尚未提供地址，因此暂不配置同步目标。

Gitee 仓库创建后，在本机执行 `git remote add gitee <实际仓库地址>`，先核对 `git remote -v`，再将需要的分支和标签分别推送到 `gitee`。不要把 GitHub 地址误填为 Gitee 远程；目前不预设镜像地址。
