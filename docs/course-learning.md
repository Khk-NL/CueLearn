# CueLearn 课程学习开发说明

产品定位、开源项目分工与后续复用原则见[产品定位与开源复用路线](product-positioning.md)。本文记录当前功能与运行配置；规划中的语义检索和社区能力不计入当前验收。

## 功能流程

1. 启动 PocketBase，打开 CueLearn 的「语境学习」页，保存本机或 HTTPS 服务地址，注册并登录。
2. 首次登录时由用户选择是否导入本机旧生词。导入只增加账号记录，不删除本地词表；重复词条跳过。
3. 在播放器的字幕中查词并收藏。已登录时，应用将单词、原句、视频指纹、字幕序号和秒数保存到当前账号；本地收藏仍保持原有行为。
4. 在「生词复习」查看到期卡片，先根据原句和视频原声回忆，再显示释义并选择「忘记／模糊／记得」。三档分别映射到 FSRS 的 Again／Hard／Good；排程只从 `review_events` 作答历史重建，统计展示到期数、今日完成数和近七日记得比例。短期复习到期后页面会自动更新队列。
5. 创建笔记本，选择最多五个已有视频。所选视频需有字幕。可以提问、生成摘要、小测验、保存手写笔记；AI 回答按论述标注字幕编号，点击编号或出处可跳转到原视频时间点。

## 数据和边界

PocketBase 0.40 系列使用 `pb_migrations/202610010000_course_learning.js` 建立 `vocabulary_items`、`word_contexts`、`review_events`、`notebooks`、`notebook_sources`、`notes`、`quiz_attempts` 和 `events` 集合。每个业务集合都有 `owner`，服务端集合规则限制本人读写。视频文件不上传；`media_key` 是文件大小及首尾采样的 SHA-256 指纹，本机路径仅保存在应用本机设置中。

笔记本问答只读取当前笔记本选中资料的字幕。主进程为字幕行编号，要求模型将每条论述关联到字幕编号，再映射为正文中的可点击引用；未知编号会报错。旧版没有正文编号的已保存笔记仍展示出处列表。资料为空、字幕太短、超出首版处理范围、字幕已变化或本机文件缺失时会显示明确提示。AI 服务没有配置时不会伪造回答。

登录令牌只保存在主进程内存中；退出登录、切换 PocketBase 地址或重启应用后需要重新登录。PocketBase 网络中断时，学习操作显示请求错误；本地播放和原有本地词表不依赖学习服务。

首次以 CueLearn 名称启动时，应用会在新的用户资料目录尚无对应文件时复制旧版配置、本地数据库和播放器偏好；原目录不删除。旧版默认文档存储目录已存在时继续使用该目录，避免已收藏片段失联。用户也可在设置中明确选择新的存储位置。

## 本机启动

项目要求 Node.js 22 和 Yarn 1。将官方 PocketBase 0.40 系列可执行文件放到系统路径中，在仓库根目录执行：

```powershell
pocketbase serve --dir pb_data --migrationsDir pb_migrations
yarn install --frozen-lockfile
yarn start
```

开发机可以分别在两个终端运行前后端。首次运行 `yarn start` 会执行上游资源下载脚本。请勿把 `pb_data/`、本机用户资料、视频、字幕或密钥提交到 Git。

远程服务由使用者最后填写：在「语境学习」设置 HTTPS PocketBase URL，在「设置 → 服务与资源」设置 AI 接口地址、密钥和模型。仓库不包含远程服务地址或凭据。Gitee 镜像仓库尚未提供地址，因此暂不配置同步目标。

Gitee 仓库创建后，在本机执行 `git remote add gitee <实际仓库地址>`，先核对 `git remote -v`，再将需要的分支和标签分别推送到 `gitee`。不要把 GitHub 地址误填为 Gitee 远程；目前不预设镜像地址。

## 验证建议

- 用两个账号分别建立生词和笔记本，确认无法读取或伪造写入对方数据。
- 重复收藏同一个词，检查同一视频同一字幕行不会重复增加语境；重启后重新登录，确认词和复习记录仍在。
- 分别选择三个复习评分，检查下一次到期时间和统计变化。
- 用两段带字幕的视频建立笔记本，核对 AI 引用文本、视频标题和跳转时间。
- 断开 PocketBase、删除本机视频或更换字幕，确认学习页给出清楚提示，同时本地播放器仍可工作。
