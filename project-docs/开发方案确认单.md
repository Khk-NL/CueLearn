## 二、技术选型确认

| 层 | 技术 | 落地方式 |
| --- | --- | --- |
| 桌面界面 | Electron、React、TypeScript | 保留播放器、字幕和本地词汇界面，新增学习中心。 |
| 本机业务 | Electron 主进程及受限 IPC | 处理视频、字幕、本机路径映射，并访问 PocketBase；登录令牌只存主进程内存。 |
| 账号与数据 | PocketBase 0.40 系列 | 保存用户、生词语境、复习事件、笔记本、笔记和测验；集合规则按 owner 隔离。 |
| 复习排程 | ts-fsrs | 三档评分对应 Again、Hard、Good；从作答事件回放计算下次到期时间。 |
| AI 资料学习 | 应用已有模型配置与 AI SDK | 仅将所选视频的字幕交给模型，回答和题目必须映射到真实字幕行及时间点。 |

**选型理由：** 本机视频与字幕不适合当作跨设备播放地址上传；PocketBase 管理需要持久保存的个人学习数据。项目基于 DashPlayer 的播放器和本地能力开发，保留其开源来源和许可声明，课程新增部分集中在学习服务与界面。

**协作节奏：** 使用 GitHub 分支提交和集成；每周同步进度、检查贡献及演示流程。Gitee 仓库地址待创建后补充。

## 四、接口约定

PocketBase 集合使用自动生成的 REST 接口；桌面界面通过内部 IPC 调用主进程，不直接持有 PocketBase 令牌。以下为当前实现所对应的主要业务调用。

| 功能 | 接口 / 路径 | 主要数据 |
| --- | --- | --- |
| 普通用户登录 | PocketBase `POST /api/collections/users/auth-with-password` | 邮箱、密码；令牌仅保存在主进程内存。 |
| 生词保存 | IPC `learning/word/save` → PocketBase `vocabulary_items`、`word_contexts` | 单词、释义、视频指纹、原句、字幕序号和秒数。 |
| 提交复习 | IPC `learning/review` → PocketBase `review_events` | 词条、评分和作答时间。 |
| 创建笔记本 / 关联资料 | IPC `learning/notebook/create`、`learning/notebook/add-source` | 笔记本名称、已有视频和字幕。 |
| 字幕问答 / 摘要 / 测验 | IPC `learning/notebook/answer`、`learning/notebook/summary`、`learning/notebook/quiz/create` | 仅使用所选字幕，返回可跳转出处。 |
| 出处回跳 | IPC `learning/playback` | 根据媒体指纹查找本机视频，返回视频记录和时间点。 |

**通用约定：** HTTP 数据为 JSON。PocketBase 集合规则限制每位用户只能访问自己的记录；主进程检查本机媒体映射。远程 PocketBase 和 AI 服务地址由使用者最后配置，仓库不预置凭据。

## 五、数据模型、采集与当前进度

| 对象 | 集合 / 位置 | 用途 |
| --- | --- | --- |
| 用户 | PocketBase `users` | 普通学习账号认证。 |
| 生词与语境 | `vocabulary_items`、`word_contexts` | 保存词、释义、字幕原句与可回跳的媒体指纹。 |
| 复习事实 | `review_events` | 保存每次评分，计算到期队列、今日完成和近期记得比例；不另存易冲突的排程状态。 |
| 笔记本资料 | `notebooks`、`notebook_sources` | 限定问答使用的视频与字幕范围。 |
| 笔记与测验 | `notes`、`quiz_attempts` | 保存手写笔记、带出处的回答、题目和作答。 |
| 媒体路径 | 本机设置 | 保存视频指纹到本机路径的关联，不作为跨设备播放地址上传。 |

PocketBase 初始迁移还建立了 `events` 集合，但当前应用没有向它写入学习行为，也没有以它生成统计；期末展示不得宣称已实现独立事件采集。当前统计来自 `review_events` 和现有学习记录。后续若确需通用事件埋点，再明确采集目的、字段和展示方式。

**当前实现：** 播放器与字幕能力、生词收藏、PocketBase 账号、FSRS 复习、笔记本资料关联、字幕出处、问答与测验的代码已接入。代码审查后的文件夹视频列表、回跳参数、生词批量导入和媒体关联问题已修正。远程 PocketBase 地址及 AI 服务由使用者后续填写。

**验证边界：** TypeScript 静态检查已通过；全新 PocketBase 0.40.4 实例的集合迁移、带引号单词查询和两个账号的读取隔离已验证。本次改动文件的针对性 lint 为 0 error、9 个既有 warning；完整 lint 仍有 5 个既有 error 和 57 个 warning。完整 Vitest 为 366 项通过、26 项失败、22 项跳过，失败集中在词典临时目录权限和播放修复测试。真实双账号、远程服务和已配置 AI 的端到端流程仍需在对应环境验收。具体结果以仓库 `docs/course-learning.md` 的最新验证记录为准。
