## 四、接口约定（接口契约）

PocketBase 路径为其自动生成的 REST 接口；`learning/...` 为桌面应用内部 IPC 路径，由渲染进程调用主进程。接口表以已接入的主要流程为准。

| 接口 | 方法 | 路径 | 入参（简述） | 返回内容（简述） | 主责人 |
| --- | --- | --- | --- | --- | --- |
| 普通账号登录 | POST | `/api/collections/users/auth-with-password` | `{identity, password}` | `{token, record}`；令牌仅由主进程持有 | 梁 |
| 收藏生词及语境 | IPC invoke → PocketBase POST | `learning/word/save` → `vocabulary_items`、`word_contexts` | 单词、释义、字幕原句、视频指纹、序号和时间点 | 已保存记录；重复词条仅补充新语境 | 李 |
| 提交复习评分 | IPC invoke → PocketBase POST | `learning/review` → `review_events` | `{wordId, rating}`；评分为忘记、模糊或记得 | 保存作答事件；下次到期时间由事件历史推导 | 郑 |
| 查询学习首页 | IPC invoke | `learning/overview` | 当前登录账号 | `{words, stats}`，含到期队列和今日、近期统计 | 郑 |
| 创建笔记本并添加资料 | IPC invoke | `learning/notebook/create`、`learning/notebook/add-source` | 名称、已有视频记录 ID | 笔记本 ID；带字幕的资料关联 | 肖 |
| 字幕资料问答 | IPC invoke | `learning/notebook/answer` | 笔记本 ID、问题 | 回答正文与可核对的字幕出处 | 肖 |
| 出处回跳 | IPC invoke | `learning/playback` | 媒体指纹、字幕起始秒数 | 本机视频记录 ID、跳转秒数 | 严 |

**通用约定：** 数据传输使用 JSON。PocketBase 返回其原生记录及错误；IPC 使用项目已有的类型化返回和错误传递，不统一包装成样例中的 `{code, message, data}`。PocketBase 令牌只保存在 Electron 主进程内存；业务集合规则限制账号只能访问自己的记录。笔记本问答、摘要和测验使用同一组已选字幕资料。

## 五、数据模型与学习行为采集

| 数据对象 | 拟建表 / 集合要点（一句话） | 用途 |
| --- | --- | --- |
| 用户 | `users`：普通账号认证与身份标识 | 登录和隔离学习记录。 |
| 生词与视频语境 | `vocabulary_items`、`word_contexts`：单词、释义、原句、媒体指纹、字幕序号与时间 | 收藏真实语境并从卡片返回视频。 |
| 复习作答记录 | `review_events`：所属用户、词条、评分和作答时间 | 回放 FSRS 排程，计算到期数、今日完成数和近期记得比例。 |
| 笔记本与资料 | `notebooks`、`notebook_sources`：笔记本及所选视频的字幕关联 | 限定 AI 问答的资料范围。 |
| 笔记与测验 | `notes`、`quiz_attempts`：正文、真实字幕引用、题目与答案 | 保存笔记、回答、测验及作答。 |
| 本机媒体映射 | 应用本机设置：媒体指纹到视频、字幕路径的关联 | 跨设备记录不上传本机绝对路径；换设备后重新关联文件。 |

**采集接口采用：** ☑ 主进程通过 PocketBase 自动接口写入 `review_events`；不采用 xAPI。初始迁移中存在 `events` 集合，但当前没有通用事件上报实现，不能把它写成已采集的数据来源。

**采集哪些行为、如何最小化：** 当前明确记录每次复习评分及时间；收藏、笔记和测验保存业务所需记录。视频文件不上传，远端仅保存必要的媒体指纹、标题、字幕引用和账号归属。

**数据如何展示：** 学习首页显示待复习数、今日完成数、近七日记得比例；笔记本显示测验作答结果，并允许点击引用回到视频核对。

**采集的 JSON 示例（主进程写入 `review_events`）：**

```json
{"owner":"user_id","word_item":"word_id","rating":"remembered","reviewed_at":"2026-10-08T10:00:00Z"}
```
