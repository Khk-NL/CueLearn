## 二、技术选型确认

| 层 | 本组拟使用的技术 | 落地说明 |
| --- | --- | --- |
| 前端 | Electron、React、TypeScript | 构建桌面应用，完成视频播放、字幕、复习和笔记本页面。 |
| 本地服务 | Electron 主进程 | 负责读取本地视频与字幕、提取片段，并通过 IPC 与界面通信。 |
| 后端与数据库 | PocketBase | 管理账号、生词、复习记录、笔记本及学习行为数据；通过集合访问规则隔离用户数据。 |
| 学习行为采集 | PocketBase `events` 集合 | 应用直接提交必要的学习事件，不采集视频文件内容。 |

**选型理由：** 视频播放和字幕处理依赖本地文件，适合保留在桌面端；账号及学习记录需要持久保存，由 PocketBase 承担后端职责。模板样例使用实训平台和 FastAPI，本组方案改用 Electron 主进程处理本地业务。

**协作节奏：** 在GitHub上创建自己的分支。每周固定进行一次查看贡献度、进度同步。各模块负责人提交可运行成果后，由组长集成并检查主要学习流程。

## 四、接口约定

以下为拟实现的核心接口契约。PocketBase 集合路径采用其自动生成的接口；`notebook/ask` 是桌面应用内部 IPC 调用，并非 PocketBase HTTP 接口。

| 接口 | 方法 | 路径 | 入参简述 | 返回内容简述 | 建议主责人 |
| --- | --- | --- | --- | --- | --- |
| 用户登录 | POST | `/api/collections/users/auth-with-password` | `{identity, password}` | `{token, record}` | 梁 |
| 保存生词 | POST | `/api/collections/vocabulary_items/records` | 单词、释义、所属用户 | 生词记录 | 李 |
| 保存视频语境 | POST | `/api/collections/word_contexts/records` | 生词、视频标识、原句、时间点 | 语境记录 | 郑 |
| 提交复习结果 | POST | `/api/collections/review_events/records` | 生词、评分、作答时间 | 复习记录 | 李 |
| 创建学习笔记本 | POST | `/api/collections/notebooks/records` | 名称、所属用户 | 笔记本记录 | 肖 |
| 字幕资料问答 | IPC invoke | `learning/notebook/answer` | 笔记本、问题、选定资料 | 回答及字幕出处 | 肖 |
| 上报学习行为 | POST | `/api/collections/events/records` | 行为类型、对象、时间 | 事件记录 | 梁 |

**通用约定：** HTTP 数据使用 JSON。PocketBase 自动接口沿用其原生返回和错误格式；IPC 接口单独约定成功结果与错误信息，不把两类接口写成同一种返回结构。用户数据的读写权限由 PocketBase 集合规则限制。

## 五、数据模型与学习行为采集

| 数据对象 | 拟建集合要点 | 用途 |
| --- | --- | --- |
| 用户 | `users`：账号与认证信息 | 登录和识别学习者 |
| 生词 | `vocabulary_items`：用户、单词、释义；下次复习时间由复习事件推导 | 生成个人词库与到期队列 |
| 单词语境 | `word_contexts`：关联生词、视频标识、原句、字幕时间点 | 从卡片返回原视频 |
| 复习记录 | `review_events`：关联用户与生词、评分、作答时间 | 计算复习安排和学习统计 |
| 笔记本 | `notebooks`、`notebook_sources`：名称及关联的视频资料 | 管理问答使用的资料范围 |
| 学习事件 | `events`：用户、行为、对象、时间 | 展示学习次数和主要操作情况 |

**采集方式：** 直接写入 PocketBase `events` 集合。首版只采集“收藏生词、提交复习、创建笔记本、提交测验”等与学习统计有关的事件，不上传整部视频或无关个人信息。

**数据展示：** 在应用内展示今日待复习数、已完成数、近期复习情况和笔记本测验结果。

**事件 JSON 示例：** 

`{"verb":"review_submitted","object":"word_record_id","rating":"remembered","occurred_at":"2026-10-01T10:00:00Z"}`
