## 一、任务目标与交付结论

本次依据课程《业务后端改造与数据采集交付》两页要求，整合小组的数据模型、业务接口、SQLite存储、行为采集和统计展示，完成成功、404、422及零参与者统计验证。

CueLearn的核心业务是：观看视频时收藏单词及字幕语境，复习时记录评分和作答时长，再通过报表了解学习投入和复习情况。本周交付围绕“收藏—复习—记录行为—查看反馈”展开。

截至本次整合，后端127项测试全部通过；合成数据演示得到预期统计。课程API使用独立SQLite分析副本，桌面正式账号和FSRS数据仍由PocketBase管理。报告不将课程API测试等同于完整桌面应用或远程AI验收。

## 四、数据设计与接口契约

### 4.1 存储内容

| 表 | 内容 | 学习价值 |
| --- | --- | --- |
| users | 匿名user_key | 保留包括零复习者在内的统计范围 |
| vocabulary_items | 单词、释义、归属及创建时间 | 形成复习对象 |
| word_contexts | 原句、媒体指纹、字幕序号与时间点 | 保留视频语境 |
| review_events | 词条、评分、复习时间与作答时长 | 计算投入、自评情况和课程到期数 |
| learning_events | 谁、何时、对什么、做什么 | 记录学习行为轨迹 |
| desktop_captures | 匿名事件键、内容摘要及收据 | 原子采集与重传去重 |

统计在查询时生成，不另存一份可能与事实记录矛盾的学习概况。

### 4.2 业务接口

| 方法与路径 | 用途 | 正常响应 |
| --- | --- | --- |
| POST /vocabulary_items | 收藏词条和语境 | 201 |
| GET /vocabulary_items/{id} | 查询词条 | 200；不存在404 |
| POST /review_events | 保存复习评分及可选时长 | 201；词条不属于该匿名用户时404 |
| GET /review_events | 查询匿名用户的复习记录 | 200 |
| POST /events | 独立行为上报 | 201 |
| POST /desktop/captures | 桌面成功操作的原子分析快照 | 首次201、同内容重试200、冲突409 |
| GET /reports/overview、/report/data | 同口径统计JSON | 200 |
| GET /report | HTML学习统计报表 | 200 |
| GET /health | 健康检查 | 200 |
| DELETE /admin/reset | 本机演示重置 | 200；不得用于真实学习库 |

《开发方案确认单》中的`learning/word/save`、`learning/review`、`learning/overview`是桌面IPC业务接口；课程HTTP端分别对应词条保存、复习保存和报表查询，不是将IPC路径直接当作HTTP路由。当前仓库未发现独立命名的《接口契约确认单》，本次以现有确认单及`docs/course-api.md`对照，若教师要求指定表单，需据同一契约补填。

### 4.3 桌面与后端的关系

React通过受限IPC调用主进程；主进程先保存PocketBase业务，再按用户配置向本机课程服务采集匿名快照。计时累计卡片可见且未等待提交的时间；隐藏或等待期间暂停。课程`vague`对应桌面`unsure`。

课程采集默认关闭，用户保存本机HTTP地址后启用。一次SQLite事务写入词条、语境、可选复习、行为及收据，避免部分成功。采集失败会独立提示，不回滚已成功的PocketBase业务；没有持久化自动补发队列，不应为补采集重复评分。

## 五、学习分析与实际展示

报表分别聚合词条与复习后LEFT JOIN，避免一个用户的多词条、多记录交叉相乘。主要指标包括词条数、复习数、今日完成数、近七日记得比例、历史平均作答时长及课程到期数。

近七日记得比例是自评分布，不是测验正确率；平均时长忽略null但保留真实0。无复习用户的比例与平均时长为null，页面显示“—”。课程到期规则为忘记立即到期、模糊一天、记得三天，与正式桌面FSRS排程分开。

### 本次合成数据演示结果

在独立临时SQLite中，通过真实FastAPI TestClient及应用生命周期执行：

1. 为`anon-demo-a`收藏context及字幕语境，返回201。
2. 为该词提交remembered、4200毫秒，返回201。
3. 为`anon-demo-b`上报一次字幕提示请求但不复习，返回201。
4. 查询两个统计JSON入口，统计行一致。
5. 查询合法但不存在的词条返回404；提交词条ID为0的评分返回422。

| 匿名用户 | 词条数 | 复习次数 | 今日完成 | 近七日记得比例 | 平均时长ms | 到期数 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| anon-demo-a | 1 | 1 | 1 | 100% | 4200 | 0 |
| anon-demo-b | 0 | 0 | 0 | — | — | 0 |

第二行证明未参与复习者不会被关联查询漏掉。数据均为合成样例，不是同学真实学习成绩，也不作为学习效果提升的实证。

## 八、限制与后续工作

- 当前课程服务无认证，只监听可信本机；匿名标识不是账号权限。不得开放公网或声称具备生产环境隔离。
- 不上传真实姓名、凭据和本机路径；敏感键检测不能识别任意文本中的个人信息，原句仍须由使用者选择适宜内容。
- 当前桥接不补录历史、不同步删除，也没有自动补发队列；完整桌面与真实远程接口仍需另行验收。
- 保留课程固定间隔与正式FSRS的区别；笔记本、AI问答等不属于本周Python采集后端的全部实现范围。

本周交付完成业务模型、接口、独立事件采集、学习统计展示及自动化验收的核心流程。组员后续从main建立分支并通过PR协作，避免直接覆盖其他成员成果。
